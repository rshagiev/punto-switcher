# Resource provenance

This release retains compatibility resources from Punto Switcher for macOS 2.1.5 (build 1724), as requested by the project owner:

- `Resources/ps.dat.txt`: language rules, decoded from `ps.dat` (CP1251; XOR 0xAA except CR/LF), then encoded as UTF-8. Line endings and trailing rule whitespace are normalized to match the parser.
- `Resources/triggers.dat.txt`: trigger list converted from CP1251 to UTF-8.
- `Resources/oracle-resources.json`: SHA-256 fingerprints of the original input tables.
- `Resources/Sounds/*.wav`: event sounds from that installation.

These are derived or copied resources, not independently generated language data or original audio. Conversion of the encoding does not change their provenance. This repository does not assert ownership of these resources or grant a new license for them. No upstream redistribution license has been established in this release preparation.

`Resources/AppIcon.icns` is generated by this project's `Scripts/make-icon.swift` using native drawing primitives. Swift source implements the application's behavior; it is not the original application's source code.
