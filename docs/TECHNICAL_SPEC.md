# Punto Native 2.0 - техническая информация

Punto Native - переключатель русской и английской раскладки для macOS 14+ на Apple Silicon. Текущая версия не поддерживает Intel. Конвертация работает локально; дополнительное редактирование с Luna использует Codex CLI по команде пользователя.
