## 3. Modifier-Only Hotkey Detection

### Детальная state machine

```
                           ┌───────────────────────────────┐
                           │      IDLE STATE               │
                           │  modifiersWerePressed = false │
                           └───────────────────────────────┘
                                         │
                        ┌────────────────┼────────────────┐
                        │                │                │
                 flagsChanged      flagsChanged     keyDown
                 (Cmd+Opt+Shift    (частичные        (любая
                  все нажаты)      модификаторы)     клавиша)
                        │                │                │
                        ▼                │                │
           ┌───────────────────────┐     │                │
           │   MODIFIERS PRESSED   │     │                │
           │ modifiersWerePressed  │◀────┘                │
           │      = true           │                      │
           └───────────────────────┘                      │
                        │                                 │
            ┌───────────┼───────────┐                     │
            │           │           │                     │
     flagsChanged  flagsChanged  keyDown ─────────────────┤
     (все ещё      (ВСЕ          (любая                   │
      нажаты)      отпущены)      клавиша)                │
            │           │           │                     │
            ▼           │           │                     │
        (wait...)       │           │                     │
                        │           │                     │
                        ▼           ▼                     ▼
           ┌───────────────────────────────────────────────────┐
           │              CHECK TRIGGER                         │
           │                                                    │
           │  if modifiersWerePressed && noModifiersPressed:   │
           │      if (now - lastTriggerTime) > 0.5s:           │
           │          ✓ TRIGGER onConvertLayout()              │
           │          lastTriggerTime = now                     │
           │      else:                                         │
           │          ✗ debounce - skip                        │
           │                                                    │
           │  modifiersWerePressed = false                      │
           └───────────────────────────────────────────────────┘
                                   │
                                   ▼
                           ┌───────────────┐
                           │  IDLE STATE   │
                           └───────────────┘
```

### Отмена при нажатии клавиши

```
           ┌───────────────────────┐
           │   MODIFIERS PRESSED   │
           │ modifiersWerePressed  │
           │      = true           │
           └───────────────────────┘
                       │
                       │ keyDown (Cmd+V, Cmd+Z, любая клавиша)
                       ▼
           ┌───────────────────────┐
           │ modifiersWerePressed  │
           │      = false          │
           │                       │
           │ → Hotkey отменён      │
           └───────────────────────┘
```

### getSelectedText() — полный flow

```
                     getSelectedText()
                           │
                           ▼

│       │                                                     │

│       │                                                     │

│                          │                                  │
│                          ├── .text(str) → return str       │
│                          ├── .empty → return nil           │
│                          └── .failed → continue            │
└─────────────────────────────────────────────────────────────┘
                           │ .noFocus or .failed
                           ▼
┌─────────────────────────────────────────────────────────────┐
│  ПОПЫТКА 2: AX API через app.focusedUIElement               │
│  (обход для Safari/Electron)                                │
│                                                             │
│  getAppFocusedElement()                                     │
│       │                                                     │
│       ├── fail → continue                                  │
│       │                                                     │
│       └── success → tryGetSelectedText(appElement)         │
│                          │                                  │

│                          ├── .empty → return nil           │
│                          └── .failed → continue            │
└─────────────────────────────────────────────────────────────┘
                           │ .failed
                           ▼
┌─────────────────────────────────────────────────────────────┐
│  ПОПЫТКА 3: Рекурсивный поиск в children                    │
│                                                             │
│  searchForSelectedText(element, depth=0)                    │
│       │                                                     │
│       ├── depth >= 5 → return nil                          │
│       │                                                     │
│       └── for child in children:                           │
│               tryGetSelectedText(child)                     │
│               searchForSelectedText(child, depth+1)         │
│                          │                                  │
│                          ├── found → return text           │
│                          └── not found → continue          │
└─────────────────────────────────────────────────────────────┘
                           │ not found
                           ▼
┌─────────────────────────────────────────────────────────────┐
│  ПОПЫТКА 4: Clipboard Fallback (Cmd+C)                      │
│                                                             │

│  getSelectedTextViaClipboard()                              │
│       │                                                     │

│       ├── pasteboard.clearContents()                       │
│       ├── CGEvent Cmd+C (cgAnnotatedSessionEventTap)       │
│       ├── Poll 10x каждые 20ms                             │
│       │   └── После 60ms: retry с cghidEventTap            │
│       ├── Проверить clipboard изменился                    │
│       ├── Проверить != previousContent                     │

│                          │                                  │
│                          ├── text → return text            │
│                          └── nil → return nil              │
└─────────────────────────────────────────────────────────────┘
```

│          │ h │ e │ l │ l │ o │ ! │ ... │   │   │   │                    │
