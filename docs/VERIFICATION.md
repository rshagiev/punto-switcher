# Проверки версии 2.0.0

Проверки проведены на Apple Silicon при подготовке релиза 13 сентября 2026 года.

## Автоматические проверки

`swift run -c release PuntoChecks` проходит. Проверяются карты раскладок, приоритеты правил, сочетания клавиш, профили приложений, Unicode, независимое отключение правок и выбор глубины обработки.

Для языкового индекса 1 023 строки сравниваются с последовательным применением правил. К концу этого этапа выполнено 1 084 утверждения; затем идут проверки профилей и обработки текста. Этот тест проверяет правильность реализации поиска. Качество самих языковых правил он не измеряет.

GitHub Actions проверяет сборку и состав пакета. `Scripts/audit-bundle.sh` сверяет встроенные таблицы и звуки, подпись, архитектуру arm64 и отсутствие личных настроек и локального пути обновлений.

## Проверки в приложениях

Во время разработки проверялись Safari (input, textarea и contenteditable), Codex, Terminal и Ghostty. Проверки включали повторную конвертацию, отмену, смену фокуса, сохранение буфера обмена, защищённые поля и профили приложений.

При установке подготовленной сборки контрольная сумма файла настроек не изменилась. В окне настроек отображалось подключение Codex и сохранились пользовательские сочетания.

## Luna

Проверки с реальными запросами показали:

- «Промпт» учёл самопоправку CSV → JSON, сохранил число 42, запрет удаления и порядок «сначала план, затем код».
- В другом примере сохранились ссылка, путь к файлу и нерешённый выбор между таблицей и списком.
- После уточнения инструкции сохранилась фраза о неизвестном сроке.
- Во время генерации «Собрать мысль» удалось вернуться к готовому «Промпту»: запрос отменился, кешированный результат появился сразу.

Есть и известная ошибка: в дополнительном примере режим «Промпт» пропустил число 42. Этот режим применяется через окно проверки. Сохранение всех деталей моделью не гарантируется.

## Релизный пакет

DMG прошёл проверку `hdiutil verify`. SHA-256 загруженного файла совпал с локальной суммой. Исполняемый файл внутри образа совпал с установленным приложением.

При переходе от кандидата к 2.0.0 Swift-код и языковые правила не менялись. Обновлены номер версии, документация, подпись и образ диска.

## Как повторить

### Регрессия Command + точка (issue #2)

`PuntoChecks` проверяет запись физической клавиши 47 с левым и правым
Command, включая событие клавиши без флага Command после `flagsChanged`.
Также проверяются JSON round-trip, отсутствие повторной записи при отпускании,
отпущенный Shift, сочетание одних модификаторов и сброс записи.

Для проверки на macOS в отдельной тестовой конфигурации:

1. Назначьте Command + точка команде «Включить / выключить автопереключение».
   Повторите с левым и правым Command. Кнопка должна показывать `⌘.`.
2. Перезапустите приложение: сочетание должно сохраниться. В `settings.json`
   у соответствующей команды должны быть `key: 47` и `modifiers: 1048576`.
3. В изолированном текстовом поле нажмите сочетание: состояние автопереключения
   должно измениться один раз. Точка без Command не должна запускать команду;
   отпускание Command после сочетания не должно запускать её повторно.
4. Проверьте запись только Command (нажать и отпустить), Escape и смену
   приложения во время записи. После отмены новая запись не должна наследовать
   старые модификаторы.

9 октября 2026 года на Apple Silicon со Swift 6.3.3 прошли `PuntoChecks`,
полная сборка с подписью `Punto Local Code Signing` и аудит пакета.
Дополнительная временная проверка вызовов `KeyboardEngine.handle` с
синтетическими `CGEvent` подтвердила запись с левым и правым Command,
включая отсутствующий флаг у точки, передачу `flagsChanged`, поглощение
клавиши и её отпускания, подпись `⌘.`, сохранение и повторное чтение JSON,
однократное выполнение команды, отсутствие повторного выполнения при
автоповторе и отпускании, точку без Command, запись одних модификаторов
и сброс через Escape. Проверка использовала копию исходников с временным
каталогом настроек; события в систему не отправлялись.

Дополнительно на Mac владельца репозитория проверена установленная сборка:
запись с физической клавиатуры показала `⌘.`, JSON сохранил `key: 47` и
`modifiers: 1048576`, после перезапуска подпись сохранилась. Владелец
подтвердил физическое включение и выключение автопереключения через ⌘+точка.
Исходные настройки восстановлены побайтно; исправленная сборка оставлена
установленной с прежней подписью. Обе стороны Command проверены синтетически;
фактическая последовательность событий с компьютера автора issue не получена.

```sh
swift run -c release PuntoChecks
bash Scripts/build-app.sh
bash Scripts/audit-bundle.sh
```

Для проверки в интерфейсе используйте отдельное тестовое поле. Запишите исходный текст, фокус, раскладку и буфер обмена. Выполните конвертацию несколько раз, продолжите набор, смените поле и проверьте отмену.

Для Luna измените исходный текст, пока выполняется запрос. Быстрая замена должна отмениться. Затем проверьте переключение режимов во время генерации и возврат к готовому варианту.

Релиз рассчитан на macOS 14+ и Apple Silicon. Защищённые поля не обрабатываются. Сборка без нотарификации Apple. Переход с 2.0.4 и более ранних версий требует установки DMG из GitHub Releases.

## Проверка Sparkle 2

- `PuntoChecks` и `check-layouts.swift` прошли. На macOS 27 с установленными Command Line Tools сборка использовала `SDKROOT=/Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk`: SDK 27 из той же установки не смог загрузить макросы SwiftUI.
- Собраны пакеты без канала и с тестовым каналом. Пройдены строгая проверка вложенных подписей, проверка DMG, повторный аудит приложения из смонтированного DMG и распакованного ZIP, а также проверка EdDSA-подписей ZIP и appcast штатным `sign_update`.
- Контроллер `Updates.swift` запустился в отдельном тестовом пакете и разрешил ручную проверку при выключенной автопроверке. Переключение настройки обновило значение в Sparkle.
- Изолированный тестовый macOS-пакет использовал тот же собранный Sparkle.framework и локальный HTTP-сервер. Sparkle отклонил ZIP с изменёнными байтами и appcast с изменёнными release notes. Ответ 404 оставил старую версию на месте. После восстановления подписанных файлов установщик заменил 2.0.5 на 2.0.6 и перезапустил пакет.
- На отдельной копии самого Punto с самоподписанным сертификатом ручная проверка показала 2.0.6 и заметки. После нажатия Install Update → Install and Relaunch открылась 2.0.6, а выключенная автопроверка сохранилась. В стенде использовался локальный HTTP, а разрешение Accessibility копии не выдавалось. Снимки сохранены в `Evidence/punto-ota-*.jpg`.
- Перед публикацией остаются первый запуск скачанного DMG и OTA с публичным HTTPS на чистом Mac, проверка Gatekeeper, Accessibility и клавиатурного ввода. Подробности в [схеме выпуска](OTA.md).

## Проверка 2.0.6

- На Mac собран ARM64-пакет с подписью `Punto Local Code Signing`. Его designated requirement совпадает с установленной 2.0.5. Для сборки на этом Mac использован SDK 26.5. Проверены `PuntoChecks`, `check-layouts.swift`, подписи пакета и контрольная сумма DMG.
- В изолированных настройках формата 2.0.5 сохранились шорткат и профили. Проверены пауза профиля, сохранение после перезапуска, восстановление наследования общих настроек и снятие старого исключения.
- Прямые вызовы обработчика в изолированной копии подтвердили однократный учёт автоматической и ручной конвертации, пропуск тайм-аута и отмены. Тестовые события в систему не отправлялись.
- В тестовой копии открыта панель после обновления, проверены раскрытие подробностей, отказ и переключение на недельный график. Отсрочка скрыла приглашение из «Сегодня». Для этого прогона использовались тестовые числа и подготовленное состояние. Снимки в `Evidence/punto-206-runtime-consent.jpg` и `Evidence/punto-206-runtime-week.jpg`.
- С клиентом `URLSession` и перехватом запросов через тестовый `URLProtocol` проверены отсутствие отправки до выбора, повтор отдельного события с прежним UUID, сохранение ID установки после перезапуска и очистка очереди при выключении. PostHog Cloud EU принял синтетическое событие `punto_integration_check` в формате клиента. В Safari подтверждены сохранённое событие, выключенное создание профилей, удаление клиентского IP и приостановленная трансформация GeoIP.
- Отдельный подписанный Sparkle-стенд с локальным каналом отклонил изменённый ZIP и оставил версию 2.0.5. После восстановления подписанного ZIP стенд установил пакет 2.0.6. Версия и подпись установленных файлов проверены; автоматический перезапуск в этом прогоне отключён. Рабочий публичный канал оставался на 2.0.5.
- Тестовая 2.0.6 с прежним требованием подписи запустила обработчик с действующим Accessibility. Нажатия, отправленные инструментом в TextEdit и Safari, дошли до редакторов в обход системного перехватчика Punto. Для сквозной проверки конвертации нужен набор, который проходит через системный `CGEventTap`. Установленная на Mac рабочая 2.0.5 снова запущена с прежними настройками.
